 Midnight Dream Station 🌙✨

Midnight Dream Station is an immersive, atmospheric portfolio web application built for the **haX.baby 48-Hour Online Hackathon**. It blends interactive visual elements, responsive design, and creative storytelling to showcase developer projects and experimental web interfaces.

---

## Features

- **Interactive Dashboard:** Modular interface sections designed for smooth navigation and dynamic content rendering.
- **Responsive Layout:** Fully optimized for desktop, tablet, and mobile viewport displays using modern CSS and Vanilla JavaScript.
- **Dynamic Styling:** Custom animations, immersive visual themes, and sleek UI components tailored for developer showcases.

---

## Tech Stack

| Layer | Technologies |
| :--- | :--- |
| **Frontend** | HTML5, CSS3, Vanilla JavaScript |
| **Styling & UI** | Custom CSS, Responsive Flexbox/Grid |
| **Environment** | Visual Studio Code, Git, GitHub |
